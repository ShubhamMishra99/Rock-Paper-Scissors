# 🪨📄✂️ Rock Paper Scissors Game

## 🎯 Objective
The objective of the Rock, Paper, Scissors game is to choose a gesture (rock, paper, or scissors) that defeats your opponent's gesture according to the game rules.

## 📜 Rules
- **Rock** beats **Scissors**
- **Scissors** beats **Paper**
- **Paper** beats **Rock**
- If both players choose the same, it's a **Draw**

## 🎮 How to Play
- The game is played between **you and the computer**
- Click one of the buttons: **Rock**, **Paper**, or **Scissors**
- The computer randomly selects its move
- The result (win/lose/draw) is displayed immediately

## 💻 Tech Stack
- **HTML** – Structure  
- **CSS** – Styling and Layout  
- **JavaScript** – Game Logic

## 🖼️ Game Interface
- ✅ Buttons for Rock, Paper, Scissors
- ✅ Display of Player & Computer choice
- ✅ Result message with emoji
- ✅ Interactive, responsive, and stylish design

## 🚀 How to Run
1. Clone or download the repository
2. Open `index.html` in any web browser
3. Enjoy the game!
